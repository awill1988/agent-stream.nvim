1. INTRODUCTION                                             *agent-stream-intro*

agent-stream.nvim is a Neovim plugin designed to monitor, visualize, and
coordinate external agents and system processes (such as background LLMs,
code generation tasks, or CLI tools running in a tmux pane) without requiring
tight coupling or custom agent integration.

It uses Neovim's native libuv (`vim.uv`) filesystem events to detect changes
made to loaded buffers and file-explorer paths, computes line-level diffs
via `vim.diff`, and renders non-destructive virtual text, virtual lines, and
sign column markers in real time.

==============================================================================
2. ARCHITECTURE & FINGERPRINTS                    *agent-stream-architecture*

Traditional POSIX metadata (mtime, ctime, uid, gid) does not distinguish
between an AI agent process and an interactive human user running under the
same system account.

Attribution is heuristic: AGENT_NAME supplies an explicit hint; otherwise,
tmux panes are scored by command, directory prefix, and active status. The
plugin does not inspect process ancestry or /proc; check_proc is unused.

BufWritePost suppresses filesystem events for that path for 500 ms. This is
a timing heuristic, not change-tick isolation; external writes within that
window can also be suppressed. Histogram diffs preserve buffer text and undo
history during preview. Accept replaces buffer contents with the previewed
disk snapshot. Reject writes current buffer contents, including unsaved edits,
back to disk.

3. SETUP & CONFIGURATION                                   *agent-stream-config*

Configure the plugin in your Neovim configuration:
>lua
    require("agent-stream").setup({})
<

No mappings are installed by default. Opt in to individual actions:
>lua
    require("agent-stream").setup({
        debounce_ms = 150,
        auto_reload_unmodified = false,
        show_signs = true,
        show_virtual_lines = true,
        show_explorer_badges = true,
        attribution = {
            enabled = true,
            check_tmux = true,
            check_proc = true,
        },
        explorer = {
            provider = "neo-tree",
        },
        keymaps = {
            accept = "<leader>aa",
            reject = "<leader>ar",
            next_hunk = "]a",
            prev_hunk = "[a",
        },
    })
<

keymaps defaults to false. Only supplied actions are mapped; false disables an
individual action. Explicit mappings replace global mappings on those keys.
Repeated setup removes only mappings still owned by the plugin.

Theme defaults use native groups and are restored on ColorScheme without
overwriting theme definitions. AgentStreamSignAdd/Delete/Change link to
Added/Removed/Changed. AgentStreamAdd/Delete/Change link to DiffAdd/Delete/Change;
AgentStreamBadge links to DiagnosticInfo and AgentStreamVirtDelete to Comment.
>lua
    require("agent-stream").setup({
        highlights = { AgentStreamBadge = { fg = "#80a0c0" } },
        symbols = { badge = "", add = "+", change = ">" },
        signs = { add = "+", delete = "-", change = "~" },
        sign_priority = 10,
        show_summary = true,
    })
<
Each explicit highlight replaces its complete default definition and is reapplied
after theme changes. Use default = true to preserve an existing theme definition.
Symbols must be empty or printable strings occupying at most two display cells.
sign_priority is an integer from 0 through 65535. Higher-priority signs win when
gutter space is limited. show_summary, show_signs, and show_virtual_lines can each
be disabled. Editor options and the installed vim.notify handler are preserved.

Migration: default shortcuts are now opt-in, signs inherit native colors instead
of GitSigns groups, and decorations use ordinary text without a special font.
Existing explicit mapping tables and public commands/actions remain supported.

manage_autoread defaults to true. Watched file buffers temporarily disable native
autoread so checktime cannot bypass review. Detach restores the original local
setting only while the plugin still owns it. User option changes relinquish
ownership. Global autoread and unrelated buffers are untouched. Set
manage_autoread = false to opt out. auto_reload_unmodified separately opts into
plugin-controlled acceptance for clean buffers.

4. COMMANDS & KEYMAPS                                    *agent-stream-commands*

:AgentStreamAccept [bufnr]                          *:AgentStreamAccept*
    Apply external disk changes cleanly into the buffer.

:AgentStreamReject [bufnr]                          *:AgentStreamReject*
    Reject incoming external changes and rewrite current buffer text to disk.

:AgentStreamNextHunk                                *:AgentStreamNextHunk*
    Jump cursor to the next external diff hunk.

:AgentStreamPrevHunk                                *:AgentStreamPrevHunk*
    Jump cursor to the previous external diff hunk.

:AgentStreamClear                                   *:AgentStreamClear*
    Clear all active diff decorations for the current buffer.

:AgentStreamFocus <file> [line] [col]               *:AgentStreamFocus*
    Focus the specified file and navigate cursor position.

:AgentStreamReveal <file>                           *:AgentStreamReveal*
    Reveal the specified file in the active file explorer.

:AgentStreamHighlight <file> <start> <end> [ms]     *:AgentStreamHighlight*
    Temporarily flash/highlight lines to indicate agent attention.

:AgentStreamAnnotate <file> <line> <message>        *:AgentStreamAnnotate*
    Render a temporary virtual annotation message.

:AgentStreamStatus                                  *:AgentStreamStatus*
    Display active watches, diffs, and server socket information.

5. EXPLORER INTEGRATION                                 *agent-stream-explorer*

For `neo-tree.nvim`, add the agent-stream badge component to your config:
>lua
    require("neo-tree").setup({
        filesystem = {
            components = {
                agent_stream_badge = require("agent-stream.explorer.neo_tree").component,
            },
            renderers = {
                file = {
                    { "icon" },
                    { "name", use_git_status_colors = true },
                    { "agent_stream_badge" },
                },
            },
        },
    })
<

==============================================================================
6. EXTERNAL CLI & RPC CONTROL                                *agent-stream-rpc*

Set rpc = { enabled = false } to prevent publishing RPC discovery. Local commands
and Lua actions remain available. Background badges do not load Neo-tree. Set
show_explorer_badges = false to disable badges, or explorer = { provider = false }
to disable both badges and reveal through the Neo-tree adapter.

The repository provides `bin/agent-ctl` for external agent scripts:
>bash
    agent-ctl focus src/main.rs 42 0
    agent-ctl reveal src/main.rs
    agent-ctl highlight src/main.rs 40 45 2000
    agent-ctl annotate src/main.rs 42 "refactoring error handling"
    agent-ctl accept src/main.rs
<
